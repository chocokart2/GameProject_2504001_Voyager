- ` - 전이`는 뭐냐고요? A 씬에서 B 씬으로 전이를 하고 싶을 때, A 씬 항목 안에 들여쓴 메뉴로 해당 내용을 적고 안에 B 씬을 언급하는거예요. 덤으로 전이 조건도 적을거고요.

- 메뉴 씬
	- 프로그램이 시작될 때의 메인 메뉴 씬
	- 전이 : 항해 씬(게임 시작 버튼 누름)
- 항해 씬
	- 기능 : 본 생존 게임이 진행되는 구조. 단일 스테이지를 진행한다라고 봐도 됨.
	- 기능 2 : 동시에 튜토리얼이기도 함(슈퍼마리오 1-1 스테이지 철학) -> 즉시 게임에 돌입하는데, 플레이어의 각종 기능을 직접 하면서 알려주는 방향임
	- 전이
		- 월드맵 씬(조건 : 함선이 목표한 지역 노드에 도착하여 항해가 종료된 경우)
		- 메뉴 씬(조건: UI에서 나가기 버튼을 누른 경우)
- 월드맵 씬
	- 기능 : 전체 맵을 보여주며, 동시에 전체 스테이지를 보여준다는 의미로 본다.
	- 전이
		- 지역 씬(조건 : 이전 씬이 항해 씬이고, 플레이어가 방금 노드 지역에 도착한 경우, UI에서 "접근하기" 버튼을 누름.)
		- 항해 씬(조건 : 플레이어가 존재하는 노드 지역의 인접한 노드 지역을 누름)
		- 승리 씬(조건 : 플레이어가 있는 노드 지역이 목적지인 경우 전이)
- 지역 씬
	- 기능 : 플레이어가 해당 지역에 자원을 수집할 수 있음
	- 전이 : 월드맵 씬(UI에서 돌아가기 버튼을 누름)
- 승리 씬
	- 기능 : 플레이어가 목표를 도달했음
	- 전이 : 메뉴 씬(UI에서 메뉴로 돌아가기 버튼을 누르면 이동)
