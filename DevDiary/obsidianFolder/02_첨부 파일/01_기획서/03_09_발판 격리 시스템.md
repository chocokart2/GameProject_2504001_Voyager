- 발판 격리 시스템
	- 씬 : 항해 씬
	- 개요
		- 특정 부위의 통제권을 잃으면 그 구역을 함선에서 떼어 내 피해 확산을 막는 시스템 (기획서의 격리 전략 참조)
		- 전제 : 함선의 발판들은 그래프 구조 (이 문서의 그래프는 항해 씬의 함선 내부 그래프이며, [[03_01_월드맵 시스템]]의 지역 노드 그래프와는 별개)
			- 함선 그래프의 정점 = 발판 / 파괴 가능한 발판
			- 함선 그래프의 간선 = 발판 체인
		- 서사적 의미 : 함선의 일부를 포기해서라도 엔진과 사람을 지킨다
	- 카테고리 : 격리 수단
		- 문 잠금
			- 기능 : [[03_03_건물 시스템]]의 문을 잠가 경로를 차단
			- 구조(발판 연결)는 유지되므로 다시 열 수 있음
			- 괴물은 문을 통과할 수 없음 (파괴로 엔트리 포인트 생성은 가능)
			- 잠금 / 해제의 조작 방식과 소요 시간은 (미정)
		- 체인 해제
			- 기능 : 두 발판 사이의 연결(발판 체인)을 끊어 구역을 물리적으로 분리
			- 해제 후 다시 연결할 수 있는지는 (미정)
			- 해제의 조작 방식과 소요 시간은 (미정)
	- 카테고리 : 구역 판정
		- 구역 : 발판 체인으로 서로 이동 가능하게 이어진 발판의 집합 (그래프의 연결 요소)
		- 본체 구역 : 엔진이 속한 구역 (엔진이 파괴되면 게임 오버이므로 기준으로 삼음. 기준은 (미정))
		- 분리 구역 : 체인 해제로 본체 구역과 끊어진 구역
		- 체인 해제나 발판 파괴가 일어날 때마다 구역을 다시 계산
	- 카테고리 : 분리 구역의 처리
		- 분리 구역에 남은 리소스 / 보관함 / 건물은 함께 포기 (기획서의 격리 전략 제약)
		- 분리 구역의 발판과 건물의 최종 처리(소멸 / 표류)는 (미정)
		- 분리 구역에 남은 승무원, 플레이어, 에너미의 처리는 (미정)
		- 승무원 사전 대피 : [[03_07_명령 시스템]]의 추종 / 철수 명령
	- 카테고리 : 엔트리 포인트와의 관계
		- [[03_08_엔트리 포인트 시스템]]에 따라, 발판 주변에 발판이 없는 곳은 엔트리 포인트가 됨
		- 체인 해제로 발판이 떨어져 나가면 새 경계가 생기는데, 그곳이 엔트리 포인트가 되는지는 (미정)
	- 카테고리 : 제약
		- 함선 크기가 제한되어 있어 무한정 쓸 수 없음 (기획서의 격리 전략 제약)
