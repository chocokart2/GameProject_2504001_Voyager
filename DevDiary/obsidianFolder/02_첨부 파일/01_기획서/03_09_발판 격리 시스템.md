- 발판 격리 시스템
	- 씬 : 항해 씬
	- 기능 : if ("발판 혹은 파괴 가능한 발판이 박살난 경우") -> then ("")
	- 규칙 1 : 파괴 가능한 발판의 연쇄 파괴
		- 조건 : 파괴 가능한 발판이 파괴(플레이어, 승무원, 에너미)된 경우
		- 결과 : 파괴 즉시, 그 칸의 "4칸 기준 인접하다"에 해당하는 칸 중 파괴 가능한 발판을 파괴한다 ([[01_01_용어집]] 참조)
		- 연쇄 : 이 규칙으로 파괴된 발판도 같은 규칙을 적용받는다. 따라서 4칸 기준으로 이어진 파괴 가능한 발판 무리는 한꺼번에 파괴된다
		- 일반 발판은 연쇄 대상이 아니며, 연쇄는 일반 발판에서 멈춘다
	- 규칙 2 : 엔진과 끊어진 발판의 파괴
		- 조건 : 발판 혹은 파괴 가능한 발판이 파괴된 경우 (규칙 1의 연쇄 파괴가 모두 끝난 뒤에 판정)
		- 연결 : 발판 / 파괴 가능한 발판이 "4칸 기준 인접하다"로 이어진 경로가 엔진까지 존재하면 "엔진과 연결되어 있다"고 한다. 경로는 발판과 파괴 가능한 발판만 지나간다 ([[01_01_용어집]] 참조)
		- 결과 : 파괴 후 엔진과 연결되지 않은 모든 발판과 파괴 가능한 발판(일반 발판 포함)을 즉시 파괴한다
		- 엔진이 파괴된 경우는 이 규칙이 아니라 게임 오버로 처리한다 ([[03_03_건물 시스템]]의 엔진 참조)
	- 규칙 3 : 파괴되는 발판 위 대상의 처리
		- 조건 : 발판 혹은 파괴 가능한 발판이 파괴된 경우 (규칙 1, 규칙 2로 파괴되는 발판도 모두 포함)
		- 결과 : 파괴되는 발판 위에 있는 캐릭터(에너미, 승무원, 플레이어)와 건물을 전부 파괴한다
