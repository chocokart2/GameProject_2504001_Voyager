- 캐릭터 시스템
	- 공통된 캐릭터 규칙
		- 캐릭터끼리는 같은 칸에 설 수 없어요.(예를 들어 미니언과 플레이어는 서로 다른 칸에 있어요)
		- AI 캐릭터의 짧은 행동은 [[03_13_캐릭터 AI 시스템]], 캐릭터별 행동 패턴(FSM)은 [[03_14_캐릭터 행동 패턴]] 참조
		- 모든 캐릭터(플레이어, 승무원, 에너미)는 위 아래 오른쪽 왼쪽으로 움직입니다. 대각선으로 움직이지 않아요
		- 가장 가까운 것을 고르는 대상은 유클리드 거리이고, 모든 에너미는 정렬된 큐를 가집니다.
	- 카테고리 : 일반
		- 플레이어
			- 씬 : 항해 씬
			- 이동 : 칸 단위로 한 칸씩 이동한다 (로그라이크식). 시간은 실시간으로 진행되며 턴제가 아니다
			- 입력 : 상하좌우 4방향 (WASD). 대각선 이동은 없다
			- 이동 간격 : 한 칸을 이동하는 데 걸리는 시간. 값은 [[05_00_밸런스 값]] 참조
			- 이동 가능 조건 : [[03_03_건물 시스템]] 표 참조
			- 소속 칸 : 칸 좌표 기준 ([[01_01_용어집]] 참조)
			- 체력 : [[05_00_밸런스 값]] 참조
			- 공격 방식 : (미정)
		- 승무원
			- 간단한 AI. 플레이어 명령을 따르며 작업장 등에 배치 가능
			- 사망 시 패러사이트에게 감염될 수 있음
	- 카테고리 : 에너미
	- 에너미 공통
		- 목표 : 플레이어 제거 / 승무원 제거 / 함선 시설 파괴 / 방어 시설 파괴
		- 항상 밤에만 활동
		- 미니언
			- 작고 약한 에너미. 승무원 / 플레이어를 보면 달려드는 단순한 AI
			- 표적 순위와 행동 패턴은 [[03_14_캐릭터 행동 패턴]] 참조
			- 일정 간격마다 함선 여기저기에 둥지 생성 (간격 / 최대 개수는 [[05_00_밸런스 값]] 참조)
			- 대응 : 둥지를 먼저 파괴 / 범위 공격 마법
		- 미니언 둥지
			- 일정 간격마다 미니언 생성 (3가지 지원 기능) (간격은 [[05_00_밸런스 값]] 참조)
				- 다른 둥지로 텔레포트
				- 주변 미니언 체력 회복
				- 새로운 미니언 생성
		- 크롤러
			- 함선의 주요 "기능 장치"를 최우선 공격 목표로 삼음
			- 특수 경로탐색 : 플레이어의 시야와 발광석이 없는 구역을 우선 이용해 숨어서 이동
		- 패러사이트
			- 엔트리 포인트에서 출발, AI 승무원을 가장 먼저 공격하고 사망한 AI 승무원을 감염시킴
		- 감염된 승무원
			- 플레이어 시야 안에서는 명령을 따름 (감염 여부를 알기 어려운 긴장 요소)
			- 시간이 지나면 좀비 승무원으로 변함
		- 좀비 승무원
			- 플레이어 명령을 따르지 않음
			- 플레이어 / 건강한 승무원 / 감염된 승무원을 단순 공격
		- 타이탄
			- 함선 외벽을 파괴하여 엔트리 포인트를 생성
			- 벽이나 문을 파괴하여 다른 괴물들이 침입할 수 있게 만듦

- 캐릭터별 체력 / 공격력 / 공격 간격 / 이동 간격 / 시야 수치는 [[05_00_밸런스 값]] 참조
