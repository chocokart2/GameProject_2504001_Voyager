- 건물 시스템
	- 카테고리 : 구조물
		- 발판
			- 기능 : 건물 시스템 중에서, 발판과 파괴 가능한 발판을 제외한 객체들을 위에 설치할 수 있음
			- 기능 : 발판 옆에 발판 혹은 파괴 가능한 발판을 설치할 수 있음
			- 서사적 의미 : 함선의 프레임, 각종 생명체들이나 물체들이 무중력 공간에서 자신의 몸을 고정시키면서 안전하게 이동할 수 있게 함.
		- 파괴 가능한 발판
			- 기능 : 플레이어가 직접 파괴할 수 있고, 혹은 
		- 벽
			- 안과 밖을 구별하고 물이 차오르지 않게 함
			- 괴물은 통과할 수 없음 (파괴로 엔트리 포인트 생성은 가능)
		- 문
			- 공간과 공간을 구분. 잠글 수 있음
			- 괴물은 통과할 수 없음 (파괴로 엔트리 포인트 생성은 가능)
	- 카테고리 : 무장
		- 발사기
			- 발리스타 / 대포 / 마법 발사 장치
			- 발판 위에 설치, 원거리로 투사체 발사
		- 발광석
			- 밤 시야 확보용 광원. 개수 제한 / 분실 가능
		- 기폭 장치
			- 에너미 근처에서 자동 기폭, 혹은 신호 마법으로 기폭
			- 사용 시 소멸하며 피해를 줌
	- 카테고리 : 필수 장치
		- 엔진
			- 기능 : 해당 객체가 파괴되면 게임이 오버됨
			- 서사적 의미 : 함선이 이동
	- 그외
		- 작업장 : 아이템을 다른 아이템으로 바꿀 수 있음
			- 기능 : 아이템 + 시간 -> 
			- 근세 공구가 배치된 가구
			- 플레이어 / 승무원이 배치되면 시간과 재료를 투자하여 아이템 획득
		- 보관함 : 아이템을 보관해둘 수 있음
