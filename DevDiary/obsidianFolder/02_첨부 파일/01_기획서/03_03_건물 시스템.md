- 건물 시스템
	- 공통 : 
		- 모든 건물은 1 x 1 사이즈를 차지함. 한 칸에 바닥 카테고리에 해당하는 건물 하나 + 그 위에 (바닥을 제외한 카테고리)에 해당하는 건물 하나를 올릴 수 있다.
		- (아이템 -> 건물)모든 건물들은 아이템화된 것들이 존재함. 그 아이템을 설치하면 그 건물이 설치됨. (예를 들어 발판의 경우, 발판 아이템이 있고, 그 아이템을 사용하면 발판을 설치하는등)
		- 파괴된 건물은 아이템으로 변하지 않는다.
		- 건물은 플레이어 시야 안의 칸에만 설치할 수 있다 ([[03_10_시야 시스템]] 참조)
	- 카테고리 : 바닥
		- 발판
			- 기능 : 건물 시스템 중에서, 발판과 파괴 가능한 발판을 제외한 객체들(건물 시스템에 해당하는 것 / 캐릭터 시스템에 해당하는 것)을 위에 설치할 수 있음
			- 기능 : 발판 옆에 발판 혹은 파괴 가능한 발판을 설치할 수 있음
			- 서사적 의미 : 함선의 프레임, 각종 생명체들이나 물체들이 무중력 공간에서 자신의 몸을 고정시키면서 안전하게 이동할 수 있게 함.
		- 파괴 가능한 발판
			- 기능 1 : 건물 시스템 중에서, 발판과 파괴 가능한 발판을 제외한 객체들(건물 시스템에 해당하는 것 / 캐릭터 시스템에 해당하는 것)을 위에 설치할 수 있음
			- 기능 2 : 발판 옆에 발판 혹은 파괴 가능한 발판을 설치할 수 있음
			- 기능 3 : 플레이어가 직접 파괴할 수 있고, 혹은 승무원에게 명령을 내려서 파괴를 명령할 수 있음
	- 카테고리 : 칸막이
		- 벽
			- 기능 : 캐릭터가 통과할 수 없는 벽.
		- 문
			- 기능 : 캐릭터가 통과할 수 없는 벽.(닫힌 상태)
			- 기능 2 : 플레이어 혹은 승무원이 이 문을 캐릭터들이 통과 가능하게 열린 상태로 만들 수 있다.
	- 카테고리 : 무장
		- 발사기
			- 기능1 : 플레이어가 올라타고, UI에서 발사 버튼을 누르면, 발사기의 이미 지정된 방향(상, 하, 좌, 우)으로 투사체를 발사함
			- 기능2: 승무원이 올라타고, 
		- 기폭 장치
			- 에너미 근처에서 자동 기폭, 혹은 신호 마법으로 기폭
			- 사용 시 소멸하며 피해를 줌
		- 발광석
			- 기능 : 밤 시야 확보용 광원.
			- [[03_10_시야 시스템]] 참조
	- 카테고리 : 필수 장치
		- 엔진
			- 기능 : 해당 객체가 파괴되면 게임 오버 ([[03_12_게임 오버 시스템]] 참조)
			- 서사적 의미 : 함선이 이동
	- 카테고리 : 아이템
		- 작업장 : 아이템을 다른 아이템으로 바꿀 수 있음
			- 기능 : 아이템 + 시간 -> 다른 아이
			- 근세 공구가 배치된 가구
			- 플레이어 / 승무원이 배치되면 시간과 재료를 투자하여 아이템 획득
		- 보관함 : 아이템을 보관해둘 수 있음

| --------- | ----- | --- | ------------------ | ---------- | ------- | ------- |

| 발사기       | 무장    | 위층  | O                  | 있음         | 발사      | X     |

| 발광석       | 무장    | 위층  | X                  | 있음         | X       | O     |
| 엔진        | 필수 장치 | 위층  | X                  | 없음         | X       | X     |
| 작업장       | 아이템   | 위층  | X                  | 있음         | 사용      | X     |
| 보관함       | 아이템   | 위층  | X                  | 있음         | 열기      | X     |
- 표 특성 설명
- 카테고리 : 편의를 위해 구분
- 층 : 한 칸에 바닥 카테고리에 해당하는 건물 하나 + 그 위에 (바닥을 제외한 카테고리)에 해당하는 건물 하나를 올릴 수 있다. -> 바닥 + 위층
- 캐릭터 통과 : 캐릭터들이 해당 건물과 겹쳐 서 있을 수 있는지 여부
- 내구도 : 0 이하가 되면 파괴되며, 공격을 얼마나 견딜 수 있는지의 값. 건물별 값은 [[05_00_밸런스 값]] 참조
- 설치를 위한 아이템 : (아이템 -> 건물)엔진을 제외한 모든 건물들은 아이템화된 것들이 존재함. 그 아이템을 설치하면 그 건물이 설치됨. (예를 들어 발판의 경우, 발판 아이템이 있고, 그 아이템을 사용하면 발판을 설치하는등) 표 참조할 것.
- 상호작용 : 플레이어나 승무원이 상호작용할 수 있는 것
- 밤 설치 : 밤에도 설치할 수 있는지 여부. 밤에는 이 칸이 O인 건물만 설치 가능 ([[03_06_시간 시스템]] 참조)
	- 의도 : 밤에도 남아 있는 빛을 기준으로 발광석을 이어 놓아 시야를 넓혀갈 수 있게 함. 배치된 발광석이 모두 사라지면 시야가 없어 설치할 수 없음 (의도한 것)
