- 캐릭터 행동 패턴
	- 씬 : 항해 씬
	- 기능 : AI 캐릭터마다 가진 FSM(상태 그래프). 각 상태에서 어떤 행동을 하고, 어떤 조건에서 다른 상태로 넘어가는지 적는다
	- 범위
		- 이 문서 : 캐릭터별 상태와 전이 (전이 조건의 판정 포함)
		- [[03_13_캐릭터 AI 시스템]] : 상태 안에서 실행하는 짧은 행동
		- [[03_04_캐릭터 시스템]] : 캐릭터 소개와 특성
		- [[05_00_밸런스 값]] : 모든 수치
- 패턴 양식
	- 캐릭터
		- 초기 상태 : 스폰 직후 들어가는 상태
		- 모든 상태 공통 전이 : 어느 상태에서든 일어나는 전이 (예 : 사망). 상태마다 반복해 적지 않는다
		- 상태들
			- 상태 이름
				- 행동 : 이 상태에서 실행하는 짧은 행동 ([[03_13_캐릭터 AI 시스템]] 참조)
				- 전이 : 위에서부터 우선순위 순서. 여러 조건이 동시에 참이면 위쪽 전이를 따른다
					- 조건 -> 다음 상태
- 미니언
	- 개요 : 작고 약한 에너미. 승무원 / 플레이어를 보면 달려드는 단순한 AI
	- 표적 순위 : 아래 순서로, 자신의 시야(En)에 보이는 것 중 가장 가까운 것을 표적으로 삼는다 ([[03_10_시야 시스템]] 참조)
		- 1. 플레이어 혹은 승무원
		- 2. [[03_03_건물 시스템]]에서 발판 항목을 제외한 건물
		- 3. 발판 혹은 파괴 가능한 발판 (인접한 발판만 파괴함)
		- "가장 가까운"의 거리 기준 : (미정)
			- 후보 : 직선 거리 ([[03_10_시야 시스템]]의 수학적 정의) / 경로상 칸 수
		- 거리가 같은 표적이 여럿일 때 : (미정)
		- 표적을 다시 고르는 시점 : (미정)
			- 후보 : 한 칸 이동할 때마다 / 현재 표적이 사라질 때만
	- 초기 상태 : (미정)
		- 후보 : 대기 (첫 판정에서 바로 추적으로 넘어감)
	- 모든 상태 공통 전이
		- 체력 0 이하 -> 사망 (처리 방식 (미정))
		- 낮이 됨 -> 제거 ([[03_10_시야 시스템]]의 에너미 시야 참조)
	- 상태들
		- 대기
			- 행동 : 대기
			- 전이
				- 표적 순위에 해당하는 것이 하나라도 보임 -> 추적
		- 추적
			- 행동 : 이동 (목적지 : 표적이 있는 칸 또는 그 인접 칸 (미정))
			- 전이
				- 아무것도 보이지 않음 -> 대기
				- 표적이 공격 범위 안 -> 공격
				- 이동 실패 (경로 없음) -> (미정)
					- 후보 : 대기 / 다음 순위 표적으로 바꿈
		- 공격
			- 행동 : 표적 공격
			- 전이
				- 표적 공격 성공 (표적 파괴) -> (미정)
					- 후보 : 대기 (다음 판정에서 새 표적을 고름) / 추적
				- 표적 공격 실패 (표적이 범위 밖) -> 추적
				- 더 높은 순위의 표적이 보임 -> (미정 : 바꿀지 여부)
