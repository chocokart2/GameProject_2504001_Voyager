
- 명령 시스템
	- 씬 : 항해 씬에서 발생합니다.
	- 개요
		- 플레이어가 승무원에게 행동을 지시하는 시스템
		- 승무원은 명령이 없으면 최소한의 자기방어만 함 (완전 자동화 금지 원칙)
		- 서사적 의미 : 좁은 함선 안에서 소리와 손짓으로 동료에게 의사를 전달함
	- 카테고리 : 명령 종류
		- 이동
			- 기능 : 지정한 발판 노드로 이동 후 대기
			- 경로는 발판 그래프의 경로탐색을 따름
			- 경로가 끊겨 있거나 격리 구역이면 실행 불가
		- 배치
			- 기능 : 작업장 / 발사기 등 시설에 승무원을 배치
			- 배치된 동안 해당 시설 기능 수행 (작업장 : 시간과 재료 소모 후 아이템 획득)
			- 해제 명령이 있기 전까지 유지
		- 수리
			- 기능 : 파괴되었거나 손상된 벽 / 문 / 시설을 복구
			- 낮에만 실행 가능 (밤에는 수리 불가)
			- 필요 재료와 시간은 (미정)
		- 전투
			- 기능 : 지정한 대상 공격 또는 지정한 위치 방어
			- 명령이 없을 때는 자기방어만 수행
		- 정찰 (확인)
			- 기능 : 플레이어 시야 밖의 지점으로 승무원을 보내 상태를 확인
			- 상세는 아래 "정찰 규칙" 참고
		- 추종 / 철수
			- 기능 : 플레이어를 따라오거나, 위험 구역에서 안전 구역으로 후퇴
			- 격리 전략에서 포기할 구역의 승무원을 대피시킬 때 사용
	- 카테고리 : 명령 전달
		- 대상 선택 : 개별 지정 (그룹 지정은 (미정))
		- 입력 방식 : 승무원을 선택 후 목적지 / 시설 지정 (명령 휠 여부 (미정))
		- 전달 조건 : 플레이어와 승무원이 일정 거리 이내일 때만 전달 가능 (거리 (미정))
			- 서사적 의미 : 괴물을 부르지 않도록 크게 외치지 않고 가까이서 지시함
		- 명령은 승무원이 받은 즉시 실행을 시작하되, 이동 시간은 소요됨
	- 카테고리 : 실행 규칙
		- 새 명령은 이전 명령을 덮어씀 (큐 방식은 사용하지 않음)
		- 실행 불가 처리
			- 경로 없음 / 대상 사망 / 시설 파괴 시 명령 취소 후 제자리 대기
			- 승무원은 취소 사실을 플레이어에게 알림 (알림 방식 (미정))
		- 거부 조건 : 체력 낮음 / 공포 상태일 때 거부하는지는 (미정)
	- 카테고리 : 정찰 규칙
		- 목적 : 플레이어 시야와 발광석 범위 밖의 상황을 확인
		- 승무원 시야
			- 승무원이 볼 수 있는 범위 : (승무원 주변 반경 N미터) ∩ (발광석 근처 M미터) 교집합 안의 영역만
			- 이 범위 밖의 에너미와 시설 상태는 승무원도 알 수 없음
			- N / M 값은 플레이어 시야보다 좁게 설정 (수치 (미정))
			- 서사적 의미 : 승무원은 불빛이 닿는 곳 중에서도 자기 가까이만 볼 수 있음 (불빛이 없으면 바로 옆도 보이지 않음)
		- 모드 1 : 시설 조회
			- 기능 : 특정 지점의 건물 상태를 쿼리
			- 얻는 정보 : 위치 / 건물 종류 / 내구도
			- 제약 : 해당 지점까지 경로가 막혀 있으면 알 수 없음
				- 경로 판정은 발판 그래프의 연결 여부 기준
				- 격리된 구역 / 체인이 해제된 구역은 조회 불가
		- 모드 2 : 순찰 이동
			- 기능 : 특정 지점까지 경로탐색하여 이동하며 에너미를 탐지
			- 승무원 시야 범위 안에 들어온 에너미만 발견으로 판정
			- 이동 중 또는 이동 완료 시 에너미를 발견하면 즉시 플레이어에게 복귀
			- 얻는 정보 : 발견한 에너미의 위치 / 타입
			- 에너미를 발견하지 못하고 도착하면 "이상 없음"을 보고하고 대기
			- 경로가 없으면 명령 취소
		- 위험
			- 순찰 중 에너미와 마주치면 복귀 이동 중에도 공격받을 수 있음
			- 사망 시 보고가 전달되지 않으며, 패러사이트에게 감염될 수 있음
		- 비용
			- 순찰 중에는 다른 배치 / 수리 / 전투 임무 불가
	- 카테고리 : 감염과의 연결
		- 감염된 승무원은 플레이어 시야 안에서는 명령을 정상 수행
		- 시야 밖에서는 명령을 수행하지 않음 (정찰 보고가 비어 있거나 지연됨)
		- 정찰에서 돌아오지 않는 승무원은 감염 의심 요소가 됨
		- 좀비 승무원은 모든 명령을 무시
		- 거짓 정보 보고는 후순위 (구현 난이도가 높아 초기 범위에서 제외)
