- 캐릭터 AI 시스템 (짧은 행동)
	- 씬 : 항해 씬
	- 기능 : AI로 움직이는 캐릭터(승무원, 에너미)가 실행하는 단일 행동을 정의한다
	- 범위
		- 이 문서 : 짧은 행동. 여러 캐릭터가 같이 쓴다
		- [[03_14_캐릭터 행동 패턴]] : 캐릭터마다 어떤 상태에서 어떤 행동을 하고, 언제 다른 상태로 넘어가는지 (FSM, 전이 조건 포함)
		- [[05_00_밸런스 값]] : 모든 수치 (이동 간격, 공격 간격 등)
	- 첫 버전은 미니언에 필요한 행동만 정한다. 다른 캐릭터를 만들 때 행동을 추가한다.
- 행동 양식
	- 모든 행동은 아래 항목을 적는다
		- 대상 : 행동에 넘겨주는 것 (없으면 "없음")
		- 하는 일 : 행동이 실행되는 동안 하는 일
		- 종료 조건 : 성공 / 실패로 나누어 적는다. 종료되기 전까지는 "진행 중"이다
- 행동 목록
	- 대기
		- 대상 : 없음
		- 하는 일 : 제자리에 가만히 있는다
		- 종료 조건
			- 성공 : 없음 (스스로 끝나지 않는다. 상태 전이로만 빠져나온다)
			- 실패 : 없음
	- 이동
		- 대상 : 목적지 칸
		- 하는 일 : 경로를 따라 이동 간격마다 한 칸씩 이동한다 (간격은 [[05_00_밸런스 값]] 참조)
			- 방향 : 상하좌우 4방향. 대각선 이동 없음 ([[03_04_캐릭터 시스템]] 공통 규칙)
			- 경로탐색 방식 : (미정)
				- 후보 : 장애물을 돌아가는 길찾기 / 목적지 쪽으로 한 칸씩 다가가기
			- 지나갈 수 있는 칸 : 발판 또는 파괴 가능한 발판이 있고, [[03_03_건물 시스템]] 표의 "캐릭터 통과"가 O인 칸
			- 가려는 칸에 다른 캐릭터가 있을 때 (캐릭터끼리는 같은 칸에 설 수 없음, [[03_04_캐릭터 시스템]] 공통 규칙) : (미정)
				- 후보 : 비켜날 때까지 대기 / 다른 경로로 우회
			- 두 캐릭터가 같은 칸에 동시에 들어가려 할 때 : (미정)
		- 종료 조건
			- 성공 : 목적지 칸에 도착 (미정 : 목적지에 인접한 칸 도착도 성공으로 볼지)
			- 실패 : 목적지까지 경로가 없음 (미정 : 경로가 없어진 즉시 실패인지, 일정 시간 기다린 뒤 실패인지)
	- 표적 공격
		- 대상 : 표적 하나 (캐릭터 또는 건물)
		- 하는 일 : 공격 간격마다 표적에게 공격력만큼 피해를 준다 (간격 / 공격력은 [[05_00_밸런스 값]] 참조)
			- 피해 : 캐릭터는 체력, 건물은 내구도를 깎는다 : (미정)
			- 공격 범위 : (미정)
				- 후보 : 4칸 기준 인접 / 8칸 기준 인접 ([[01_01_용어집]] 참조)
			- 첫 공격 타이밍 : (미정)
				- 후보 : 행동 시작 즉시 / 공격 간격만큼 기다린 뒤
		- 종료 조건
			- 성공 : 표적이 파괴됨 (캐릭터는 체력 0 이하, 건물은 내구도 0 이하)
			- 실패 : 표적이 공격 범위 밖으로 벗어남
