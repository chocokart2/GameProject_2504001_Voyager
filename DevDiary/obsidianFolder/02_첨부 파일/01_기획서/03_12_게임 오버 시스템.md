- 게임 오버 시스템
	- 씬 : 항해 씬
	- 패배 조건 (하나라도 충족 시 게임 오버)
		- 엔진 파괴 ([[03_03_건물 시스템]])
		- 플레이어 사망 ([[03_04_캐릭터 시스템]])
	- 게임 오버 시 처리
		- 게임 정지 (시간 / 에너미 / 승무원 모두 멈춤)
		- 게임 오버 UI 표시 ([[04_01_항해 씬 UI]] 참조)
	- 게임 오버 후 선택
		- 리플레이 : 항해 씬 재실행
		- 나가기 : 메뉴 씬으로 전이 ([[02_00_씬 종류]] 참조)
	- 진행이 어려우나 패배가 아닌 경우(의도한 것입니다.)
		- 밤 상태인데, 배치된 발광석이 없어서 낮이 올 때까지 아무런 행동을 할 수 없음
			- 보유한 발광석이 있어도 시야 밖이라 설치할 수 없음 ([[03_03_건물 시스템]] 공통 규칙, [[03_10_시야 시스템]] 참조)
		- 처리 : 게임 오버로 판정하지 않는다. 플레이어가 나가기 버튼으로 직접 그만둘 수 있다
			- 의도 : "사실상 패배"를 자동으로 판정하면 오판 위험이 있음
