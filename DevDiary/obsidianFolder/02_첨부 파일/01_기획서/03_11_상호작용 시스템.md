- 상호작용 시스템
	- 씬 : 항해 씬
	- 기능 : 플레이어 혹은 승무원이 건물의 기능을 사용하는 행동
	- 주체
		- 플레이어 : 직접 입력으로 상호작용한다
		- 승무원 : [[03_07_명령 시스템]]의 명령을 받아 상호작용한다
		- 에너미는 상호작용하지 않는다 (건물은 공격만 한다)
	- 대상 : [[03_03_건물 시스템]] 표에서 "상호작용" 칸이 X가 아닌 건물
	- 범위 : 주체의 시야 범위 안에 있는 모든 건물 ([[03_10_시야 시스템]] 참조)
	- 건물별 동작 : [[03_03_건물 시스템]] 표의 "상호작용" 칸 참조
	- (미정)
		- 대상 선택 방법 : 시야 안에 건물이 여러 개일 때 어떻게 고르는지 (예: 마우스 클릭)
		- 입력 : 선택한 뒤 어떤 입력으로 실행하는지
		- 소요 시간 : 즉시 끝나는 것 / 계속 머물러야 하는 것(작업장 등)
		- 점유 : 한 건물을 동시에 여러 캐릭터가 사용할 수 있는지
		- 그 칸에 가야 하는 상호작용 : 발사기 올라타기, 작업장 배치는 원거리로 되는지
		- 가림 : 벽이나 문이 시야를 가리는지
